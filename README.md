# 🎮 坦克大战 - Tank Battle

一个使用 HTML5 Canvas 制作的经典坦克大战游戏。

## 🎯 游戏特性

- 🕹️ 经典坦克大战玩法
- 🎨 精美的像素风格图形
- 💥 爆炸特效
- 🏆 计分系统
- ❤️ 生命值系统
- 🗺️ 多种地形（砖墙、钢墙、水域、树木）
- 🎖️ 保护基地任务

## 🎮 操作说明

- **方向键** ↑↓←→：移动坦克
- **空格键**：发射子弹
- **R键**：重新开始游戏

## 🎯 游戏规则

1. 消灭所有敌方坦克即可获胜
2. 保护基地（红色标记）不被摧毁
3. 避开敌方子弹
4. 砖墙可以被子弹摧毁，钢墙无法摧毁
5. 每消灭一个敌人获得 100 分

## 🚀 如何运行

1. 克隆仓库到本地：
```bash
git clone https://github.com/YOUR_USERNAME/tank-battle.git
```

2. 打开 `index.html` 文件即可在浏览器中运行游戏

或者直接在 GitHub Pages 上玩：
[在线游戏链接](https://YOUR_USERNAME.github.io/tank-battle/)
